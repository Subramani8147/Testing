# User Manual

## Signing in
Default admin: `admin` / `ChangeMe123!`. Roles: admin (full access),
technician (create/edit), viewer (read-only).

## Dashboard
Ticket/asset/SOP counts, recent tickets.

## SOPs & Knowledge Base
Search/filter by category, create/edit procedures, drag-and-drop or
Browse to attach a supporting file, click the attachment chip to open it.

## Tickets & Incidents
Auto-numbered (`INC-2026-00001`), filter by status/priority/search,
inline status/priority edits, comment thread. **Import from Excel** for
bulk-loading tickets — see `docs/IMPORT_GUIDE.md`.

## Assets
Inventory with tag/type/status/location/owner/warranty tracking.
**Import from Excel** for bulk-loading — see `docs/IMPORT_GUIDE.md`.

## User Accounts (admin only)
Create accounts, reset passwords, deactivate/reactivate.

## Settings (admin only)
Theme, storage locations, backup schedule, log retention, tray behavior.

## Keyboard shortcuts
`Ctrl+S` save · `Ctrl+F` search · `Ctrl+P` print · `Ctrl+B` backup now
